# VisionAssist 👁️‍🗨️

VisionAssist is an Android application powered by AI which helps visually impaired people with real-time environmental awareness, obstacle detection, navigation, and voice-based guidance.

The app uses Android development, Artificial Intelligence, Computer Vision, and Database Management in order to enable users to have safer and more independent mobility.

## 🚀 Key Features

🔹 Real-time object detection – The detection of objects and obstacles is carried out using computer vision.
* 🧭 Assistive Navigation – this helps users when navigating around different locations by using intelligent pathfinding.
* Voice Guidance. Gives real-time audio instructions and alerts.
– **Location Awareness** enables support for navigation by making use of location information.
⚠️ **Safety Alerts** – Issues warnings whenever potential obstacles or risks are detected.
– Android Application: This has been developed specifically as a tool for providing real-time assistance on mobile devices.
– **Local Database** – It stores the navigation data, the nodes, the edges, the risks, and all the relevant user information.
– Indoor Navigation Support employs QR-code-based location nodes in indoor navigation situations.

## 🧠 System Modules

1. **Video Processing**

   It captures and processes the user's environment.
   * Finds important objects and obstacles.

2. **Prediction & Navigation**

   It takes in information about the environment and location.
   It uses pathfinding algorithms to determine appropriate navigation paths.

3. **Real-time Assistance and Alerts**

   Turns the information that has been detected into voice instructions.
   It gives warnings about obstacles and possible risks.

## 🎯 Objective

The main aim of VisionAssist is to enhance environmental awareness and navigation for people who are visually impaired by using AI and mobile technology, which will enable them to move about more independently and safely.
